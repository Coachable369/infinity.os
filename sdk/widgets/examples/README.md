# Session counter

Choose **New Widget** in InfinityCode to start a writable copy of this 360 × 200 form. Select **Add one** in the designer to inspect its connected Python method. Edit the layout or the Event Methods tab, then choose **Generate Python** and **Export**. Save the project to retain the designer layout as well as your code.

The installed SDK includes the project as `/InfinitySDK/widgets/examples/counter.json` and its executable Python source as `/InfinitySDK/widgets/examples/counter.py`. **Add one** increments the label and **Reset** returns it to zero.
