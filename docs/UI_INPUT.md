# InfinityUI Input and Focus

Keyboard, pointer, text, and composition events enter one typed input boundary.
Focus follows semantic document order, supports forward and reverse traversal,
wraps predictably, and records modal focus roots. Hit testing selects the highest
visible actionable element. Password bytes remain in the authentication service
path and are never logged, painted as plaintext, or exposed to skins.

The login gold standard supports user selection, password entry, Sign In,
security-key discovery, Add User, recovery guidance, Options, Shut Down,
Restart, Network, and Accessibility with mouse and keyboard focus. Small pointer
motions remain 1:1 while larger gestures accelerate.

The bootstrap path gives input strict priority over animation. Virtual machines
that expose the same tablet through UEFI and USB HID use one authoritative
absolute coordinate per poll, while retaining button and wheel edges. Queued
absolute reports are coalesced to the newest position rather than rendered as a
visible backlog.

Focus traversal, pointer acceleration, and cross-window input ownership are
TESTED. Native IME provider integration is SCAFFOLDED through composition events.
