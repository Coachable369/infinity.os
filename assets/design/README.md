# InfinityOS visual design references

These references define measurable visual targets before framebuffer or shell
implementation begins. They are development sources, not runtime screenshots.

- `infinity-date-time-idesign-kit-v1.png` — Date & Time installer component
  system: typography, glass fields, map treatment, buttons, spacing, and control
  states. The runtime renderer uses the same navy/ice/cyan hierarchy and draws
  live values over the separate text-free world map asset.
