# Infinity Memory

Use the existing Eclipse Precision window chrome, AI adorner, midnight navy panel and Inter roles. The browser needs one dedicated launcher glyph. The generated 256 px transparent master is `infinity-memory-v1.png`, with the native 32-bit launcher copy in `assets/apps/infinity-memory-v1.bmp`.

The left pane presents up to six record summaries. The inspector uses a fixed heading, an expanding multiline text area, a category choice and source, timestamp and embedding details. The search field, retrieval mode and category filter sit above both panes. A status line reports matches and catalog size. Save and New use the active primary UIKit image recipe. Navigation, refresh and deletion use its secondary recipe, with normal, focused and pressed artwork. Keep the desktop compositor responsible for close, minimize and maximize.
