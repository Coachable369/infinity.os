# Continuum / InfinityOS Website

## Authoritative Emblem

`../../boot/infinity-emblem-v2.bmp` is the authoritative InfinityOS symbol.
The same-named PNG is DIFFERENT artwork and must not be used as its substitute.
Decode the BMP itself to RGBA PNG/WebP for web delivery. The decoded reference is
`../../../meetinfinityos.com/design/emblem-reference.png`.
Preserve the two balanced oval lobes, broad continuous rounded ribbon, open
interiors, and rising lower-left to upper-right foreground crossing. Never
substitute a typographic infinity glyph, knot, angular loop, or extra strands
that change its silhouette.

Broad cobalt-blue polished chrome, ice reflections and substantial sculptural
mass are the material language. It is not a silver-white glass loop.
Use the decoded BMP pixels as the primary logo, including compact brand marks.
Campaign lighting may introduce electric blue `#2765ff` and ice `#b4dbff`;
geometry must remain faithful. Use aspect-fit without
stretching, clipping either lobe, or adding free-floating decorative particles.
Existing native bootstrap geometry and animation coordinates remain unchanged.

## Website Extension

The native kit had no editorial public website system. The generated
[IDesign Kit](../../../meetinfinityos.com/design/IDesign-Kit.png) fills that gap.
The [implementation contract](../../../meetinfinityos.com/design/continuum.md)
defines exact typography, colors, controls, spacing, motion, and accessibility.
Written values override approximate generated labels and spacing.

The [web emblem](../../../meetinfinityos.com/assets/infinity-emblem.webp) is a
lossless derivative of the BMP, not a generated interpretation. The generated
macro illustration uses the decoded BMP as its material reference. The prior
silver campaign rendering and top-bar substitute are removed from this website.

The revised public motion uses a beveled 3D relief traced from the actual
emblem's silhouette and both openings. Original kit pixels map to its faces;
the unseen reverse and edge depth are reconstructed, not original 3D source.
Do not substitute a generic tube or torus knot. Scroll drives axis rotation,
and electrical pulses follow ground-plane traces. The BMP-derived logo remains
the navigation mark and static fallback. Framework use was explicitly approved
on 2026-10-20. See the implementation contract for reduced-motion behavior.

This document and website artwork are design-authoring material. They introduce
no runtime, installer, or installed-system component, and do not change any OS
packaging or native visual acceptance.
