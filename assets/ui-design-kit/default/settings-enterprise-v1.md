# System Settings

The companion reference board shows General, Appearance, Accounts, AI & Voice, Privacy, Devices, Network, Mesh, Storage, About and Input. The final tile is a control legend. Use Eclipse Precision window chrome, a persistent navigation rail, a section title, and rows aligned on a common value column. Use the packaged icon family in the navigation rail. Use native disclosure buttons for choices and checkboxes for binary values. The actual settings, screen names, bounds, typography and theme overrides come from Studio and the OS. Example metrics in the board are illustrative only.

In **Devices**, the display control cycles only through framebuffer modes the bootloader detected and the compositor can render. It shows the saved dimensions and marks a pending change with “restart.” A machine exposing just one mode has no alternate choice. A failed firmware write must leave the previously selected size intact.
