# Browser tabs — soft shoulders

36px-high tabs have long flat tops, rounded upper corners, sloping shoulders
and softly flared feet. The selected tab meets the toolbar without a bottom
border. Surfaces are dark charcoal tinted by OS Primary; subdued edges use OS
Accent. Active tabs are raised, inactive tabs recede, hover gently lifts the
surface. No neon rail, glow, polygon cuts or idle animation. Native text stays
14px; close targets stay 24px and are inset 40px to clear the shoulders.

remain bounded. Both architectures and installed/live paths use the same code.
